# ReXGroundingCT Challenge 2026 — Data Profiling & Analysis Workspace

Dedicated research workspace for **Phase 1 Data Profiling & Spatial-Text Analysis** for the **ReXGrounding Challenge @ MICCAI 2026** (3D radiological finding grounding in thoracic CT scans from free-text descriptions).

> [!IMPORTANT]
> **Repository Scope & Governance**:
> This repository is dedicated exclusively to **Data Profiling, Spatial Density Prior Mapping, HU Radiodensity Analysis, NLP Syntax Shift Profiling, 3D Component Topology, and Paper Manuscript Generation**.
> Model fine-tuning pipelines (Phase 2 & 3) consume the exported static JSON configuration bundles generated by this codebase.
